# Water

A native SwiftUI (iOS 17+) app that tracks daily water intake: progress ring, +250 / +500 ml buttons, undo, today's history with times, a 7-day bar chart and a goal you can change in Settings (default 2,000 ml). Data is saved in UserDefaults and survives restarts.

The Xcode project is generated with XcodeGen from `project.yml`. Unit tests are in `WaterTests`, the click test in `WaterUITests`.
